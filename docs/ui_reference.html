2 · Verdict and severity

✗FAIL Heaviest treatment, solid fill. Draws the eye first. Glyph plus label survive greyscale printing.
✓PASS Lightest treatment. Present but recessive — a compliant control needs no attention.
?UNKNOWN Dashed border, neutral slate. Deliberately not amber — abstention is off the severity axis, not a weaker FAIL.
INFERRED platform_default — asserted from documented default, not observed. Always shown, never suppressible.
CAT I  CAT II  CAT III Severity uses ink weight, not colour — otherwise two colour scales compete and the screen turns into a rainbow.

Telnet transmits credentials in cleartext. Any host on the path between an administrator and this device can recover the login. The control requires SSH as the only permitted transport on VTY lines.

Remediation — vetted snippet, cisco-ios / 15.x

! verify SSH reachability before applying — removing telnet ! without a working SSH session will strand remote access configure terminal line vty 0 4 transport input ssh end write memory

Rollback

configure terminal line vty 0 4 transport input telnet ssh end

Impact: existing Telnet sessions terminate immediately. Order: apply after ssh_version and AAA findings on this device. Commands are supplied from the snippet library and applied by an operator — NIRIKSHAK does not execute them.
